# Сценарий демо (3–4 минуты)

1. **Проблема (20 с).** Ошибка в ТЗ, найденная после разработки, стоит в разы дороже. Ручное ревью медленное и субъективное.
2. **Запуск (40 с).** `python -m validator docs/requirements.md -o reports/report.md -i --gold gold/defects.md`. Показать, как в консоли идут 9 шагов.
3. **Уточнения (40 с).** Агент задаёт вопросы заказчику (критерий «Уточнение»). Ответить на 1–2 вопроса и показать, что итог их учитывает.
4. **HTML-отчёт (60 с).** Индекс готовности, критичные дефекты (Ф-3 против Ф-4, GET для сохранения, 404 в разделе 403), фильтр по критичности, трассировка на критерии приёмки и «не покрыто».
5. **Доверие (30 с).** Каждое замечание с цитатой и номером строки. Верификатор и критик отсеяли N ложных замечаний, это видно в приложении.
6. **Метрика (20 с).** `report_eval.md`: полнота X из 22 по эталону, составленному вручную.
7. **Архитектура (30 с).** Схема из README: код плюс LLM, JSON-схемы, кэш, воспроизводимость, любая модель.
